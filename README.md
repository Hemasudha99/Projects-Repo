Project 
- Title: Haunted House Escape Game
- Link:https://scratch.mit.edu/projects/1184406553
Technologies:
- Scratch: Block-based
About:
- This game was designed for CS50 to practice Scratch programming. This demonstrates the use of loops, conditionals, interactions between the user and the sprite, etc. It is a fun and friendly game designed for those who love to solve mysteries.
Usage:
- Open the Scratch project and click on the green button to start playing. Reply to questions and jot down the answers as you go and solve the riddles. At the very end, plug in the answers to break free from the haunted house.
Features:
- This game is mainly based on the user's input. This involves a lot of clicking and answering using the keyboard.
